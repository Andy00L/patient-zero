# Font attribution

This directory holds two self-hosted typefaces. Both are the property of the
Indian Type Foundry (ITF) and are distributed through Fontshare.

| File | Family | Weight |
| --- | --- | --- |
| `Technor-400.woff2` | Technor | 400 Regular |
| `Technor-500.woff2` | Technor | 500 Medium |
| `Technor-700.woff2` | Technor | 700 Bold |
| `Tabular-400.woff2` | Tabular | 400 Regular |
| `Tabular-500.woff2` | Tabular | 500 Medium |
